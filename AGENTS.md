# Working with Copilot Coding Agent

**Good tasks**: small bug fixes, UI tweaks, adding tests, a11y fixes, writing docs, local refactors with clear acceptance criteria.

**Avoid assigning**: auth/secret wiring, prod-critical incidents, broad rewrites, risky migrations, or tasks needing sensitive keys or deep domain context.

**How to ask**: open an issue with the "Copilot Task" template, fill Context + Acceptance criteria + Files to touch, then assign to **Copilot**.
